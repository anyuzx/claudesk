GLE-HIPPS-DIMES stress relaxation

This note records the working interpretation of GLE-HIPPS-DIMES as a generalized Maxwell representation. The central question is whether the stress relaxation modulus G(t) can still be written as a modal sum when the Rouse-like normal modes are replaced by memory-bearing GLE modes.

Model intuition

In the original HIPPS-DIMES construction, the static ensemble is governed by a harmonic free energy over modal amplitudes. The stress response can therefore be decomposed into modal stress contributions. In the GLE extension, the modal amplitudes no longer relax as simple exponentials; each mode has a relaxation function determined by its memory kernel.

G(t) \approx \sum_p A_p \, \Phi_p(t)^2
\int_0^t \Gamma_p(t-s)\dot{\Phi}_p(s)\,ds = -\lambda_p\Phi_p(t), \quad \Phi_p(0)=1

This means the structure of the Maxwell sum survives, but the basis functions are generalized relaxation functions rather than pure exponentials. The useful object to fit is therefore not only the amplitude spectrum Ap, but also the family of mode-level memory kernels or a low-dimensional parameterization of them.

Next checks

  • Compare the fitted Ap spectrum against the HIPPS-DIMES eigenvalue spectrum.
  • Test whether one shared memory kernel shape with mode-dependent timescale is sufficient.
  • Check whether contact-survival correction explains the long-time tail without overfitting early-time decay.
  • Validate the fitted relaxation against simulation trajectories not used in fitting.
Decision note: Treat GLE-HIPPS-DIMES as a generalized modal Maxwell model for now. Do not claim that the model predicts slow relaxation from static distance maps alone until the memory-kernel parameterization is validated against held-out simulation data.
