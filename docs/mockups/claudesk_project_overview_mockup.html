Project description

Research goal

Build and validate a polymer simulation framework for studying how coarse-grained chromosome organization emerges from experimentally observed structural constraints.

The project connects curated experimental measurements, long Brownian dynamics simulations, and compact model diagnostics. The working hypothesis is that a small set of interpretable physical parameters can reproduce both static structural statistics and selected dynamical signatures.

Working scope

  • Assemble a clean training and validation dataset from experiment-derived observables.
  • Run a reproducible simulation parameter sweep with archived configuration files.
  • Compare simulated structures against target distance, contact, and relaxation summaries.
